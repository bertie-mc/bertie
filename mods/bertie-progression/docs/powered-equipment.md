# Powered equipment and utility acquisition

The captured slot patterns are in `texture-work/queued_052_layouts.json`.
Every recipe produces one item.

| Station | Output |
| --- | --- |
| 7×7 End Table | Atomic Disassembler, Chainsaw, Electric Mace, Hand Drill, Enderic Railgun, Wireless Charging Station |
| 5×5 Nether Table | Equipment Charger, Chargepad, Quantum Research Station |
| 7×7 Create Mechanical Crafting | Elytra |
| 5×5 Nether Table | Alternative Elytra |

Wireless Charging Station accepts Chargepad or Equipment Charger in the one
placeholder slot; the End Table itself is not an ingredient. Its station is
still the End Table. The Quantum station is Oritech's Advanced Augment Station,
not its basic station. AnvilCraft Jewelcrafting no longer produces Elytra.

Mechanical Fusion Anvil uses ordinary falling-anvil Block Compression. Place a
Carminite Block on an Anvil, then drop another Anvil onto them. This replaces the
manual craft and adds no high-speed collision requirement.

Rustic Glider, Rustic Glider Speed and Speed Booster are retired. Other Rustic
Engineer content remains. Existing world registry IDs remain valid.
