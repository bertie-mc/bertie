# Rustic Engineer Fix

Fixes *Rustic Engineer*'s airship and dragonfly flight - choppy turning and the pitch-dive bug.

- **Minecraft:** 1.21.1
- **Loader:** NeoForge
- **Mod ID:** `rusticengineerfix`
- **Dependency:** Requires the **Rustic Engineer** mod.

Contains only original mixin code.
