# Frozen Registry Fix

Fixes *Immersive Armors*' "Registry is already frozen" crash in large modpacks by force-initializing its `Items` class before the armor-material registry freezes.

- **Minecraft:** 1.21.1
- **Loader:** NeoForge
- **Mod ID:** `frozenregfix`
- **Dependency:** Requires **Immersive Armors**.
