# Cataclysm Fortresses

A resource-only NeoForge compatibility mod for Minecraft 1.21.1. It adds YUNG's Better Nether
Fortress structure to Cataclysm's `berserker_spawn` structure tag, allowing Ignited Berserkers to
spawn there after Ignis is defeated.

- **Loader:** `lowcodefml`
- **Mod ID:** `cataclysmfortresses`
- **Requires:** Cataclysm and YUNG's Better Nether Fortresses

The JAR contains only mod metadata and the compatibility tag; it has no Java entrypoint.

## Building

`gradle :mods:cataclysm-fortresses:assemble` builds the JAR.
